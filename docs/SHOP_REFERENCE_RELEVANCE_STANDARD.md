# Shop Reference Relevance Standard

MaintainOps shop reference charts should help a technician identify a part, avoid a known wrong match, or choose the next verification step. Rows should not be added only because they are technically possible.

## Relevance Rules

- Prefer field-useful rows over exhaustive catalogs.
- Highlight a row only when it is high-frequency, high-confusion, or high-consequence.
- Keep "common use" practical: name where the item shows up, what it is confused with, or why it is checked often.
- Keep troubleshooting notes observational. Avoid company-policy instructions, safety-program language, and opinion-only recommendations.
- Every chart should answer: what is it, where is it commonly seen, what can be confused with it, and how should it be verified.

## First Standard Pass

Three chart families were used to establish the relevance pattern:

- Wire Gauge Reference: common branch/cord sizes are highlighted because 14, 12, 10, 8, and 6 AWG repeatedly map to common shop circuits, cords, RV/welder/range uses, and common sizing mistakes.
- Socket / Wrench Close-Fit Reference: 10mm, 13mm, 14mm, and 19mm are highlighted because they are frequent field socket sizes and easy to misuse as SAE substitutes.
- Bearing Quick Reference: 6203, 6204, 6205, and 6206 are highlighted because they are common motor, pump, conveyor, fan, and gearbox bearing sizes where suffix and fit mistakes matter.

## Highlight Meaning

"Very common" means the row is worth seeing first because technicians are likely to encounter it often or lose time around it. It does not mean interchangeable, always correct, or safe to substitute without verification.

## Minimum Chart Quality

Expanded row detail should avoid loop-around navigation noise. Do not add a generic "related chart" box unless it names a direct next lookup that changes the decision.

Each chart should include:

- A practical row label.
- A sizing or identity value.
- A field note that explains why mechanics care.
- A watch point or verify-by path.
- Detail rows that include Mechanic 101, common confusion, senior tech note, verify-by, risk/signal, source family, and example context.
- Highlighted rows should get row-specific teaching text. Generic category fallback is acceptable for obscure rows, but "Very common" rows should explain the actual size/code/part, the nearby mistake, and the field reason it matters.
